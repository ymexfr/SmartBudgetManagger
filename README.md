# SmartBudget Manager

SmartBudget Manager is an Excel file that helps you follow your monthly income and expenses. It shows a chart of your spending and warns you when you go over your budget.

**File:** SmartBudget_Manager.xlsx | **Version:** 1.0 | **Currency:** euro

## What it does

- Records income and expenses
- Puts expenses in categories (Food, Transport, Rent, Health, Education)
- Calculates total income, total expenses and the balance automatically
- Shows a pie chart of expenses by category
- Shows OVER BUDGET (red) or WITHIN BUDGET (green)

## What you need

- Microsoft Excel 2016, 2019, 2021 or Microsoft 365 (or a compatible program)
- The file SmartBudget_Manager.xlsx

## How to start

1. Open the file. If you see PROTECTED VIEW, click **Enable Editing**.
2. Save a copy for your month (File > Save As).
3. On **Transactions**, select A4 to G9 and press Delete to remove the example data.
4. On **Categories**, write your monthly budget for each category.
5. On **Transactions**, add your income and expenses. Then open **Dashboard** to see the results.

## The 3 worksheets

| Worksheet | Use |
|---|---|
| Transactions | Enter income and expenses (you type here) |
| Categories | Set the budget limit of each category |
| Dashboard | Read the balance, chart and warning (do not type here) |

## Rules

- One file for each month.
- Write each amount in Income **or** Expense, not both.
- Choose Type and Category from the drop-down lists.
- Do not type in the Month column or on the Dashboard.
- Only rows 4 to 50 are counted.

## Limits

- Only the 5 categories above are shown on the Dashboard.
- The warning uses the total budget. One category over its limit only shows a negative number.
